# 群聊任务感知与共享看板设计

## 背景

办公协作中的任务、会议和决策经常自然产生在 IM 群聊中。用户通常不会在聊天后再次打开任务、日历或文档工具登记信息，导致个人承诺遗忘、团队分工分散、会议安排依赖人工推动。

本设计面向 IM Copilot 增加“群聊任务感知与共享看板”能力。机器人在群聊中保持弱存在感，默认不打扰讨论；在识别到个人承诺、公开分配、会议评审等协作信号时，按私密性和影响范围进入不同流程。

## 目标

- 自动识别群聊中的个人承诺，并生成个人 Todo。
- 个人 Todo 只在单聊中提醒和展示，避免在群内暴露个人事项。
- 自动识别公开分配、团队事项、会议或评审意图。
- 会议和评审类事项必须经过用户确认后再创建日程。
- 每个群维护共享看板，用于沉淀公开协作任务、会议、决议、风险、待定问题和资源链接。
- 支持用户主动查看群看板，并支持群管理员开启下班前定时总结。

## 非目标

- 不做完整项目管理系统。
- 不在群内公开展示普通个人承诺。
- 不自动创建日程、任务或外部资源。
- 不处理复杂权限体系，只定义 MVP 所需的最小可见性规则。
- 不要求第一版打通 PRD、PPT、白板等增强动作。

## 用户入口

### 被动识别

机器人监听群聊消息，默认不发言。系统识别以下语义类型：

- 个人承诺：说话者承诺自己在某个时间做某事。
- 公开分配：群里明确指定某人负责某事。
- 会议/评审：出现多人参与、时间、主题、同步、评审、讨论等信号。
- 普通聊天：只作为群总结素材，不生成 Todo 或日程候选。

### 主动触发

群内 @ 机器人只用于团队协作事项，例如查看群看板、总结讨论、创建会议、生成文档。个人 Todo 不通过群内 @ 机器人创建，避免用户在群内暴露个人事项。

用户可在单聊中用自然语言或已有 `/todo` 命令查看个人 Todo。

## 核心流程

### 个人隐式 Todo

当群聊中出现个人承诺时，系统抽取：

- 责任人
- 事项
- 时间或触发时机
- 来源群
- 来源消息
- 置信度

高置信个人承诺直接写入个人 Todo。低置信个人承诺通过单聊询问用户是否记录。到提醒时间后，机器人单聊发送轻提醒，内容包括事项和来源消息。

个人 Todo 永远不在群聊中公开提醒或展示。

### 公开分配任务

当群聊中出现明确公开分配时，系统写入群共享看板。公开分配任务可同时写入责任人的个人 Todo，但提醒仍只通过单聊发送。

如果任务没有明确责任人，则只进入群看板的待认领事项，不进入个人 Todo。

### 会议/评审确认

当系统识别到会议、评审、同步、多人讨论等意图时，抽取：

- 会议主题
- 候选时间
- 相关参与人
- 来源消息
- 来源群

系统不自动创建日程，而是在群内向相关人展示仅相关人可见的确认卡片。用户确认后，系统创建日程，并将日程信息写入群共享看板。

### 群共享看板

每个群维护一个共享看板。看板内容包括：

- 明确分配给某人的任务
- 团队事项
- 待认领事项
- 会议或评审候选
- 已确认日程
- 群内决议
- 风险
- 待定问题
- 相关文档、日程、PRD、白板等资源链接

看板不展示普通个人承诺。

### 群总结

用户可以在群内 @ 机器人查看今日看板或聊天概要。群管理员可以开启每日下班前自动总结。

总结内容包括：

- 今日聊天概要
- 今日新增团队待办
- 明日关注事项
- 待确认会议或评审
- 相关资源链接

## 可见性规则

- 个人承诺只进入个人 Todo，不展示在群看板。
- 公开分配任务展示在群看板。
- 公开分配任务可以进入责任人个人 Todo，但提醒只走单聊。
- 会议/评审确认卡片只对相关人可见。
- 日程创建必须由用户确认。
- 群总结只展示群级协作信息，不展示纯个人承诺。

## 置信度策略

MVP 使用高低置信度分流：

- 高置信个人承诺：直接记录个人 Todo。
- 低置信个人承诺：单聊确认。
- 无明确时间的个人承诺：不主动提醒，可作为待补时间候选。
- 无明确责任人的团队任务：进入群看板待认领，不进入个人 Todo。
- 普通聊天：只进入群总结素材。

置信度判断应优先考虑以下字段是否完整：

- 动作
- 责任人
- 时间或触发时机
- 语气是否表达承诺、分配或安排
- 上下文是否指向明确任务主题

## MVP 范围

- 被动识别个人承诺，自动生成个人 Todo。
- 低置信个人 Todo 单聊确认。
- 到点单聊轻提醒。
- 支持 `/todo` 或单聊查询个人待办。
- 识别公开分配任务，写入群共享看板。
- 识别会议/评审意图，发送仅相关人可见确认卡片。
- 用户确认后创建日程。
- 群内主动查看今日看板。
- 群管理员可开启下班前定时总结。

## 后续增强

### 提醒增强

- 提醒卡片增加完成、延后、忽略、查看原消息按钮。
- 在合适场景中提供生成 PRD、创建评审日程、整理相关文档等入口。

### 看板增强

- 看板支持待处理、进行中、已完成、待确认等状态。
- 支持按责任人、日期、来源消息过滤。
- 支持把每日总结归档成飞书文档。

### Agent 增强

- 当任务信息缺失时，Agent 单聊追问。
- 当群聊讨论长期无结论时，群总结列出待定问题。
- 当会议材料成熟时，Agent 建议生成 PRD 或 PPT。

## 演示主线

1. 群聊中自然出现个人承诺，机器人不公开回应。
2. 系统后台生成个人 Todo。
3. 到点后机器人单聊用户轻提醒。
4. 群聊中出现公开分配任务，任务进入群共享看板。
5. 群聊中出现 PRD 评审会议意图，机器人向相关人发送私密确认卡片。
6. 用户确认后系统创建日程。
7. 群里 @ 机器人查看今日看板，机器人总结团队待办、会议、聊天概要和资源链接。

## 风险与处理

- 误识别会造成打扰：通过高低置信度分流降低误提醒。
- 隐私边界不清会影响信任：个人 Todo 永远单聊展示，群看板只展示公开协作事项。
- 自动操作风险高：日程创建必须确认。
- 群总结信息过多：MVP 总结只展示团队级信息和明确公共事项。
